# 실거주 매수 판단기

한국 주택(아파트·빌라·단독·오피스텔)을 **거주·투자 목적으로 살지 말지** 판단하는 웹 대시보드입니다. 규정 기준일은 2026-09-25입니다.
빌드나 서버 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 휴대폰 앱으로 설치 (안드로이드·갤럭시)

설치형 웹앱(PWA)입니다. 홈 화면 아이콘으로 실행되고, 전체 화면으로 열리며, 인터넷이 없어도 계산 기능은 동작합니다.

1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 한 번만 바꿉니다.
2. `master`에 반영되면 `.github/workflows/pages.yml`이 테스트를 통과한 뒤 `https://kimyh1981.github.io/Personal-Project/`에 배포합니다.
3. 갤럭시에서 이 주소를 **Chrome** 또는 **삼성 인터넷**으로 엽니다. 하단 **앱 설치** 버튼을 누르거나 메뉴 → **홈 화면에 추가 / 앱 설치**를 누릅니다.

- 하단 탭: 판정 · 조건 입력 · 분석 · 후보 비교. 조건을 입력하는 동안 화면 아래에 현재 점수와 판정이 계속 보입니다.
- 아이콘을 길게 누르면 '조건 입력'과 '후보 비교' 바로가기가 나옵니다.
- 오프라인에서도 앱 파일은 열리지만 공공데이터 조회(`/api/`)는 절대 캐시하지 않습니다. 온라인일 때는 항상 최신 앱 파일을 받습니다.
- 웹 버전(GitHub Pages)은 서버 없이 공공데이터를 씁니다 (`js/direct.js`). 로컬 서버와 같은 `/api/` 경로를 브라우저가 처리합니다.

  | 데이터 | 웹 버전에서 | 필요한 것 |
  |---|---|---|
  | 실거래가 (매매·전월세), 최적지 추천 | 브라우저가 공공데이터포털 직접 조회 (CORS 허용) | 실거래가 탭에 공공데이터포털 인증키 |
  | 단지 위치·지하철역·초등학교 | 브라우저가 카카오 로컬 직접 조회 | 실거래가 탭에 카카오 REST 키 |
  | 토지이용계획 (토지거래허가·정비구역) | 브라우저가 브이월드 직접 조회 (JSONP) | 브이월드 키, 키의 서비스URL에 `kimyh1981.github.io` |
  | 서울 정비사업 단계 | 6시간마다 받아둔 전체 목록 `data/redev-seoul.json`에서 검색 (정보몽땅이 CORS 헤더를 중복으로 보내 브라우저 직접 조회 불가) | 없음 |
  | 규제 고시·법령 시행 | 6시간마다 만든 `data/regulation.json` | 저장소 비밀값 `DATA_GO_KR_KEY` |
  | 경기 정비사업 | 지원 안 함 | 로컬 서버 |

  인증키는 그 기기의 브라우저에만 저장됩니다. 로컬 서버(`npm start`)로 열면 기존처럼 서버가 조회합니다.
- **사용 안내** (`guide.html`): 메뉴별 3분 음성 안내 영상(`media/guide.mp4`, 자막 `media/guide.vtt`)과 갤럭시(크롬·삼성 인터넷)·아이폰·PC 설치 방법. 영상은 가상의 예시 프로필로 모바일 화면을 녹화하고, 오프라인 한국어 음성 합성(Supertonic 3)으로 내레이션을 넣었습니다. 서비스 워커는 영상 파일을 캐시하지 않습니다.
- 플레이스토어용 APK가 필요하면 배포 주소를 [PWABuilder](https://www.pwabuilder.com/)에 넣어 안드로이드 패키지(TWA)를 만들 수 있습니다.

## 필수 조건

판정 전에 아래 조건을 모두 채워야 합니다. 하나라도 비면 판정하지 않고 빠진 항목과 이유를 보여줍니다 (`js/conditions.js`).

| 적용 | 항목 |
|---|---|
| 공통 | 매수 목적(거주/투자/거주+투자), 지역(시·군·구), 주택 유형, 전용면적, 매매가, 확보 자금, 보유 주택 수, 연소득, 매수 예정 시점 |
| 거주 | 업무지구 통근시간, 초등학교 도보시간 |
| 투자 | 역까지 도보시간, 같은 평형 최근 실거래가, 전세 시세, 계획 보유기간 |
| 재건축 | 정비사업 단계, 종전자산 감정가(사업시행인가~이주철거), 예상 분담금 |
| 세입자 승계 | 승계할 전세보증금 |

조건이 채워지면 규제·조건을 **차단 / 주의 / 정보**로 판정합니다. 예를 들면 다음과 같습니다.

- 토지거래허가구역 아파트는 전세 낀 매수와 비거주 매수가 불가합니다. 토지거래허가는 아파트에만 적용됩니다.
- 수도권·규제지역 비거주 매수는 6개월 전입의무 때문에 주담대를 쓸 수 없습니다.
- 투기과열지구 재건축을 조합설립인가 이후에 사면 조합원 지위양도 제한에 걸립니다(매도인 10년 보유·5년 거주 예외).
- **이주비**: 종전자산 감정가 × LTV 50%로 이주비 대출을 받고, 이주 시점 주담대 잔액을 대환한 뒤 남는 순수령액으로 세입자 보증금이나 임시거주 보증금을 마련합니다. 부족분은 매수 후 여유자금과 연 저축으로 채울 수 있는지 봅니다.
- 분담금 조달, 신축 입주 시점과 희망 입주 시점, 단기 양도(2년 미만), 보유기간 < 입주까지 기간을 점검합니다.

거주·투자 목적별로 입지 점수(통근·학교·역세권·호재/악재·주택유형)와 투자 점수(실거래 대비 가격·전세가율·환금성·재건축 수익)를 0~100점으로 냅니다.

## 최적지 추천

입력한 자금·소득·목적으로 원하는 지역에서 살 만한 단지를 찾아 순위로 보여줍니다.

1. **후보 만들기**: 고른 지역(최대 6곳)의 최근 국토부 실거래가(매매·전월세)를 모아 단지·평형별 후보를 만듭니다. 최근 중위가, 전세 중위가, 준공연도, 거래 건수, ㎡당 가격의 지역 중위 대비 위치가 들어갑니다.
2. **걸러내기**: 면적·연식·예산 근처(최대 매수가 × 1.1)로 줄입니다.
3. **입지 채우기**: 직장까지 통근시간은 거리 기반으로 추정합니다. 카카오 REST 키(`KAKAO_REST_KEY`)가 있으면 단지 좌표, 가장 가까운 지하철역, 초등학교 도보시간을 조회합니다.
4. **판정**: 후보마다 기존 판정 엔진(대출 한도·세금·매달 남는 돈·규제)을 돌려 예산 초과·조건 차단을 빼고 적합도를 매깁니다.
   - 거주: 통근·현금흐름·예산 여유·역세권·학교·연식·종합 판정
   - 투자: 가격 적정성·전세가율·역세권·거래량·재건축 기대·예산·종합 판정
5. **결과**: 순위마다 핵심 숫자, 장점과 주의점을 보여줍니다. "이 단지로 상세 판정"을 누르면 판정 화면이 그 단지 값으로 채워지고, "후보 비교에 담기"를 누르면 후보 비교에 들어갑니다.

- 데이터: `npm start` 로컬 서버의 실시간 API, 또는 국토부 실거래가 CSV(여러 파일)를 씁니다.
- "예시 데이터로 보기"는 가상의 단지·시세로, 화면 확인용일 뿐 실제 값이 아닙니다.

## 내 맞춤 추천 (`my.html`, 매주 갱신)

고정한 내 조건(보유 주택 매도 자금, 월 상환 능력, 나이·노후 목표)으로 서울 단지를 순위 기준별로 나눕니다. 매수 판단기 첫 화면과 추천 탭의 **내 맞춤 추천** 버튼으로 엽니다.

| 순위 | 조건 |
|---|---|
| 1순위 | 자기자금 + 은행 대출 (월 상환 기본 한도, 최대 한도까지) · 바로 입주 · 60세 노후 월소득 ≥ 목표 |
| 2순위 | 자기자금 + 은행 대출 + 추가 자금 (월 상환 기본의 150% 이내) · 입주 늦어도 됨 (재건축 가산) · 노후 ≥ 목표의 130% |
| 3순위 | 대출 없이 · 바로 입주 · 60세 이후 소득을 더하면 노후 가능 (노후 ≥ 목표의 50%) |
| 4순위 | 대출 없이 · 바로 입주 · 집만으로 노후 ≥ 목표 |
| 5순위 | 월 상환 고소득 한도(예: 1,000만원) · 노후 ≥ 목표의 200%이고 1~4순위 최고보다 30% 이상 |
| 추가 A | 1순위 조건 + 30년 넘은 단지: 지금 살면서 재건축 기대 |
| 추가 B | 대출 없이 사고 남는 돈(1억 이상)을 굴려 노후에 보태기 |

- 교통·상권·인프라 입지 점수 45점 미만은 모든 순위에서 뺍니다. 상위 후보는 카카오로 지하철역·초등학교·대형마트·병원을 확인한 뒤 다시 매깁니다.
- 미래 시세는 단지(40%)·같은 동(40%)·구(20%)의 과거 5년·10년 ㎡당 연평균 상승률을 섞은 뒤 1.5%p 낮추고, 연 5.5%를 넘지 않게 합니다.
- 30년 넘은 단지는 서울 정비사업 정보몽땅 사업장과 같은 동·대표 지번·이름으로 짝지어 실제 단계를 붙입니다. 성사 가능성은 같은 구 재건축 사업 중 그 단계까지 온 곳이 준공·해산까지 끝난 비율(서울 비율로 보정)입니다. 서울 전체로 보면 조합설립 37%, 사업시행인가 55%, 관리처분 67%, 이주 이후 82% 이상입니다. 입주까지 기간은 단계별 평균입니다. 카드에 조합 공개 페이지(공지·총회 자료)와 서울 도시계획 지도 링크를 붙이고, 단지별로 가능성·기간·분담금을 고칠 수 있습니다.
- 30년 넘은 단지(2순위·5순위·추가 A)는 재건축 뒤 시세를 같은 동 준공 15년 이내 신축의 ㎡당가 × 면적(현재가의 2배 상한)으로 보고, 분담금(전용㎡당 300만원, 입주까지 물가 반영)을 뺀 뒤 오르는 몫은 성사 가능성만큼만 인정합니다. 주상복합·소규모 단지·60세 이후 입주는 넣지 않습니다.

### 검증: 재개발·재건축 단지는 주변 완료 단지 시세를 따라가는가

서울 25개 구 국토부 실거래(2026년 최근 6개월, 2021년 3~8월)로 확인했습니다. 대상은 전용 49~135㎡이고, 비슷한 면적(±15㎡)끼리 비교했습니다.

| 검증 | 표본 | 오차 중앙값 | 편향 | ±10% 안 |
|---|---|---|---|---|
| 2026 신축 ㎡당가 vs 같은 동 준공 15년 이내 (큰 단지) | 50 | 12.4% | +0.6% | 46% |
| 2026 신축 vs 같은 구 준신축 | 105 | 21.1% | +3.1% | 26% |
| 2026 신축 vs 구 전체 중위 (단순 비교) | 50 | 42.2% | +41.8% | 14% |
| 2021 당시 신축 vs 같은 동 준신축 | 53 | 15.1% | +9.1% | 40% |
| 2021→2026 시세: 같은 동 준신축 상승률 적용 | 47 | 5.4% | +1.3% | 79% |
| 2021→2026 시세: 구 전체 상승률 적용 | 47 | 9.7% | +7.4% | 53% |

- 신축은 같은 동 준신축 시세에 맞춰지고(편향 거의 0), 그 뒤로도 같은 동 시세를 따라 움직입니다. 구 단위로는 오차가 커서 쓰지 않습니다.
- 한계: 재건축 전후 이름이 바뀌어, 구축 → 신축 직접 사례는 실거래에서 거의 찾을 수 없습니다. 분담금·사업 기간·성사 여부는 공공데이터로 검증할 수 없는 가정이라 '내 기준'에서 조정하게 했습니다. 표본은 수십 건 수준입니다.
- 대출은 만기(기본 30년, DSR도 만기 기준)로 갚다가, 60세에 남은 대출은 집을 팔아 한 번에 갚고 후순위 지역의 작은 집으로 옮긴다고 봅니다.
- 월 상환 기본 한도에서 실제 상환을 뺀 나머지는 매달 저축(연 3%)해 60세 노후 자금에 더합니다. 4순위만 저축을 빼고 집의 미래가치만으로 판단합니다.
- 노후 월소득(현재 돈 가치)은 60세 시세에서 남은 대출과 옮겨 살 집 값을 뺀 차액을 연 4%로 쓰는 경우와 주택연금 중 큰 값에, 저축분을 더한 값입니다.
- 개인 조건은 그 기기에만 저장합니다. 공개 사이트에는 서울 시장 데이터(`data/market-seoul.json`)만 올라갑니다. 처음 한 번은 `my.html#setup=…` 개인 설정 링크로 열면 조건이 저장되고, 주소에서 바로 지워집니다. 링크에 순위 메모가 없으면 이 기기에 있던 메모·조건은 그대로 둡니다.
- 서울 시장 데이터는 배포 작업이 주 1회 모읍니다 (`tools/market.js`: 25개 구 최근 6개월 매매·전월세, 5·10년 전 매매). 저장소 비밀값 `DATA_GO_KR_KEY`가 필요합니다.
- 지난주 결과와 비교해 신규·순위 변동을 표시합니다.
- **나의 순위 조건**: 순위마다 내 메모(문장)와 실제 계산 조건을 둡니다. 계산 조건은 대출 방식(없이·은행만·은행+추가·필요·상관없음), 월 상환 한도, 노후 목표 %, 재건축 기대 반영입니다. 조건을 바꾸면 서울 전체 후보를 다시 평가하고, 새로 올라온 후보는 입지를 다시 확인합니다.
- **메모 → 조건**: 메모에 적은 지역(구·동·강남3구·마용성·노도강 등), 가격(15억 이하, 10~14억), 평형(30평대, 84㎡), 연식(신축·준신축·준공 15년 이내·구축·재건축 단지), 역세권(역 7분)을 읽어 그 순위의 조건으로 씁니다. 읽은 조건은 메모 아래 칩으로 보입니다. 그 지역에 추천이 없으면 지역만 빼고 같은 조건으로 추천이 나오는 구·동(곳 수)을 안내합니다. 지역을 바꿀지, 그대로 두고 매주 기다릴지는 직접 고릅니다.
- 순위 버튼을 누르면 그 순위 추천(최대 10곳)이 바로 아래에 펼쳐집니다.
- **찾을 지역 · 주택 종류** (내 기준, 여러 개 고르기): 구(강남3구·마용성 등 묶음 버튼 포함, 안 고르면 서울 전체)와 주택 종류(아파트·빌라·오피스텔)를 여러 개 고르면 그 안에서만 추천합니다. 내 조건으로 찾기도 이 값으로 시작하고, 구·동·종류를 여러 개 고를 수 있습니다.
- 빌라·오피스텔은 아파트가 아니어서 서울 토지거래허가 대상이 아닙니다. 그래서 세입자를 두고 나중에 입주하는 계획(매수 때 대출 없이 전세 승계)이 법상 가능하게 계산됩니다. 오피스텔 취득세 4.6%, 빌라·오피스텔 재건축 가치는 넣지 않고, 같은 동·구 통계는 종류별로 따로 냅니다.
- 빌라·오피스텔 실거래는 공공데이터포털에서 '국토교통부_연립다세대 매매 실거래가 자료', '…연립다세대 전월세…', '국토교통부_오피스텔 매매 신고 자료', '…오피스텔 전월세…'를 활용신청하면 주간 수집(`tools/market.js`)이 자동으로 함께 모읍니다. 신청 전에는 건너뛰고 화면에 '데이터 신청 필요'로 표시합니다.
- **추가 동원 가능 자금** (내 기준): 예금·가족 지원 등 갚지 않는 돈을 넣으면 '서울 매수에 쓸 현금'에 더해져 모든 순위와 매수 판단기의 '내 조건으로 찾기'에 반영됩니다.
- **내 여유자금** (순위별): 순위마다 추가로 동원할 수 있는 내 돈(예금·가족 지원 등, 갚지 않는 돈)을 넣으면 그 순위만 현금을 그만큼 늘려 서울 전체를 다시 평가합니다. 다른 순위 계산은 그대로입니다. 2순위의 '추가 자금'(빌려서 갚는 돈, 이자 반영)과는 다릅니다. 현금이 늘면 대출이 필요 없어진 단지는 '대출이 필요한 순위'(1순위 등)에서 빠지고 '대출 없이' 순위로 옮겨 갑니다.

### 거주 계획과 실거주 의무 (2026-10-01 기준)

- 서울 25개 구 아파트는 토지거래허가구역입니다(2025-10-20 ~ 2026-12-31, 연장 여부 미정). 허가 후 4개월 안에 취득하고 입주해 2년 살아야 합니다.
- 세입자 있는 집은 임대차 종료일(갱신계약 1회·최대 2년 포함)까지 입주를 미룰 수 있습니다. 단, 매수자는 **2026-05-12부터 계속 무주택**이어야 하고, 그 뒤에 집을 팔아 무주택이 된 사람은 대상이 아닙니다. 허가 신청은 2027-12-31까지입니다 ([국토부 2026-05-12](https://www.korea.kr/news/policyNewsView.do?newsId=148964215), [2026-09-17](https://www.korea.kr/news/policyNewsView.do?newsId=148972092)).
- 토지거래허가 대상 주택을 사려고 받는 주담대에는 6개월 전입의무가 없지만(허가의 실거주 의무가 대신 적용), 허가가 해제된 뒤라도 수도권·규제지역 주담대는 6개월 전입의무가 있습니다. 그래서 '나중에 입주'는 매수 때 대출 없이 세입자 전세보증금을 안고 사는 경우만 계산합니다.
- 입주할 때 돌려줄 전세금은 [그동안 살 집 전세금 + 남은 현금 + 그동안 모은 돈(월 상환 여력)]으로 내고, 모자라면 전세퇴거자금 대출(수도권·규제지역 1주택자 1억 한도, LTV·DSR 안)과 추가 자금으로 채웁니다.
- '내 기준'의 거주 계획이 '나중에 입주'여도 법상 미룰 수 없으면 바로 입주로 계산하고 이유를 보여 줍니다. 이때 그동안 살 집 전세금은 필요 없다고 보고 매수 자금에 넣습니다.
- 주담대 한도 = min(LTV 40%, 주택가격별 한도 15억 이하 6억·25억 이하 4억·초과 2억, 스트레스 DSR 40%). 스트레스 금리는 수도권 하한 3%p × 금리 유형 반영비율(주기형 40%·혼합형 80%·변동형 100%)이고, 기본은 한도가 가장 큰 주기형, 만기는 수도권 상한 30년입니다. 카드에 한도를 정한 기준(LTV·가격별 한도·DSR)을 표시합니다.

## 조건 입력: 상세 입력 · 내 조건으로 찾기

매수 판단기의 조건 입력 맨 위에서 고릅니다. 판정은 어느 쪽이든 넣은 값으로 같은 엔진이 계산합니다.

- **상세 입력**: 누구나 자기 조건을 하나하나 넣습니다. '무주택 시작일'과 '토지거래허가 기간 뒤 가정'으로 위 실거주 규정을 판정합니다.
- **내 조건으로 찾기**: 내 맞춤 추천에 저장한 내 기준을 그대로 쓰고, 매수 시기·입주 시기·구(동)만 고르면 그 지역 단지를 내 조건으로 평가해 순위(1~5순위·추가)와 함께 보여 줍니다. 입주 시기가 매수보다 3개월 이상 늦으면 세입자를 두고 사는 계획으로 계산합니다(법이 허용할 때만). 목록의 단지마다 같은 판정 엔진으로 계산한 판정 점수를 보여 주고(목록 점수 = 판정 보기 점수), 단지를 누르면 판정 입력(가격·면적·전세·현금·연소득·금리 유형·대출액·통근/역/학교)을 채워 판정합니다. 고른 단지가 없을 때 아래 막대는 '단지를 누르면 판정'으로 바뀝니다. 월 실수령은 연소득으로 추정하고 생활비는 실수령 − 월 상환 최대로 둡니다.
- **미래 그림** (판정 아래): 지금 가격 → 입주 → 5·10년 뒤 → 60세 예상 시세, 같은 동 시세(신축 ㎡당가와 비교), 30년 넘은 단지의 재건축 그림(정비사업 단계·성사 가능성·입주 예상·분담금), 같은 동 정비사업(재건축·재개발·가로주택) 목록과 입주 예상 시기를 보여 줍니다. 상세 입력에서는 비슷한 단지를 골라 같은 그림을 볼 수 있습니다.

## 소득·상환 능력

은행 DSR은 세전 소득으로 한도를 정합니다. 실제로 매달 갚을 수 있는지는 따로 봅니다.

- 입력: 대출 명의(부부 공동 / 본인 단독), 본인·배우자 세전 연소득, **월 실수령액(세후)**, **고용 형태**, 소득 증가율, 은퇴 예정 나이, 월 생활비, 기존 대출, 신용대출 잔액
- DSR 심사소득: 공동 차주는 두 사람 합산, 단독은 본인만. 신용대출은 5년 분할상환으로 봅니다.
- 매달 남는 돈 = 실수령 − 생활비 − 보유세·수선비 − 새 주담대 − 기존 대출 − 개인 차입 이자
- 위기 점검:
  - 금리 +2%p일 때
  - 한 사람 소득이 끊길 때
  - 소득이 모두 끊길 때 여유 현금으로 버티는 개월 수
  - 은퇴 시점의 대출 잔액
  - 고용 형태에 따른 소득 안정성
- 연 순저축을 비우면 '매달 남는 돈 × 12'로 재건축 이주비·분담금 재원을 계산합니다.

## 최신 공공데이터 (무조건 최신)

`npm start`로 열면 로컬 서버가 아래 공공데이터를 조회합니다. 모든 값에 조회 시각과 출처가 붙습니다. 최신 확인에 실패하면 결과에 **"최신 규제 미확인"** 경고가 붙고, 규정 파일 값을 조용히 쓰지 않습니다.

| 데이터 | 출처 | 설정 |

| 아파트 전월세 실거래가 | 국토부 RTMS 전월세 | `DATA_GO_KR_KEY` |
| 필지 토지이용계획 (토지거래허가구역·정비구역·투기과열지구 표시) | 브이월드 주소검색 → PNU → 토지이용계획속성 | `VWORLD_KEY` |

| 세법·주택법 개정 시행 | 공공데이터포털 **법제처_국가법령정보 공유서비스**(지방세법·소득세법·종부세법·주택법·부동산거래신고법·도시정비법 등, IP 등록 불필요). 키가 없으면 법제처 OC(서버 IP 등록 필요)를 씁니다. 웹 버전은 저장소 비밀값 `DATA_GO_KR_KEY`로 조회합니다 | `DATA_GO_KR_KEY` (활용신청) 또는 `LAW_OC` |

- 캐시는 짧게만 둡니다(토지이용 1시간, 정비사업 6시간, 규제 1시간). "지금 다시 확인"을 누르면 캐시를 건너뜁니다.
- 화면을 열어두면 30분마다 규제 변경을 다시 확인합니다.
- 정비사업 단계는 호갱노노와 같은 12단계입니다: 기본계획수립 → 안전진단 → 정비구역지정 → 추진위원회승인 → 조합설립인가 → 사업시행인가 → 관리처분인가 → 이주·철거신고 → 착공신고 → 일반분양승인 → 준공인가. 공공데이터의 단계별 날짜 열(예: `추진위원회승인일`)로 이력을 만들고, 날짜가 있는 가장 늦은 단계를 현재 단계로 봅니다. 현재 단계에서 지난 기간도 입주 예상 시점에 반영합니다.
- 인증키는 `config.example.json`을 `config.local.json`으로 복사해 넣습니다. 이 파일은 깃에 올라가지 않습니다.

## 예산 밖 자금 (개인 차입·근저당)

금융권 한도로는 못 사지만 개인 자금을 더하면 살 수 있는 매물도 놓치지 않도록, 개인 간 금융을 따로 계산합니다.

- 방식: 매도인 잔금 유예 + 근저당 (2026년 7월 대통령 분당 아파트 매도 사례와 같은 구조) / 가족 등 특수관계인 차입 / 지인·기타 개인 차입
- 금융회사 대출이 아니라 LTV·DSR·주담대 한도는 적용되지 않습니다. 최대 매수 가능가를 "금융권만"과 "개인 차입 포함"으로 나눠 보여줍니다.
- 비용: 채권최고액(원금 120%) 기준 등록면허세 0.2%·지방교육세·국민주택채권·법무사
- 이자는 만기까지 매달 내고 원금은 만기에 한 번에 갚는 방식으로, 매수 vs 임차·갭 투자 비교에 반영합니다.
- 점검 항목:
  - 이자제한법 20% 초과는 차단합니다.
  - 특수관계인 적정이자 4.6%보다 낮아 생기는 이익이 연 1천만원 이상이면 증여 추정입니다(안전한 원금 한도 계산).
  - 차용증·이자 지급 기록, 비영업대금 이자 원천징수(27.5%)를 확인합니다.
  - 자금조달계획서 기재와 토지거래허가 심사, 후순위 근저당과 은행 약정, 만기 상환 재원, 개인 이자 부담률을 확인합니다.
  - 규제 우회 논란 때문에 추가 규제가 나올 수 있습니다.

## 구조

```
js/policy.js   규제·세율 파라미터 (규정이 바뀌면 이 파일만 수정)
js/engine.js   순수 계산 함수 (DOM 없음, Node 테스트 대상)
js/conditions.js 필수 조건 검증·규제 판정·재건축 이주비·시기·입지 점수
js/recommend.js 실거래 후보 만들기·적합도 순위·예시 데이터
js/geo.js      시·군·구 중심과 업무지구 좌표, 통근 추정
js/charts.js   의존성 없는 SVG 차트
js/app.js      화면 제어
js/pwa.js      앱 모드 (서비스 워커 등록·설치 버튼·하단 탭)
sw.js          오프라인 캐시 (공공데이터 API는 캐시 안 함)
manifest.webmanifest, icons/  설치 정보·아이콘
tests/         node:test 단위 테스트
tools/build.js 단일 HTML 파일로 묶기
tools/server.js 로컬 서버 + 공공데이터 프록시
tools/live-data.js 최신 공공데이터 조회·파싱·짧은 캐시
```

## 명령

```bash
npm test          # 엔진 단위 테스트
npm run build     # dist/real-estate-analyzer.html 단일 파일 생성
npm start         # http://localhost:8080 로컬 서버 + 실거래가 자동 조회
DATA_GO_KR_KEY=<인증키> npm start   # 인증키를 서버에 설정 (화면 입력도 가능)
```
