# 실거주 매수 판단기

한국 주택(아파트·빌라·단독·오피스텔)을 **거주·투자 목적으로 살지 말지** 판단하는 웹 대시보드입니다. 규정 기준일은 2026-09-25입니다.
빌드나 서버 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 필수 조건

판정 전에 아래 조건을 모두 채워야 합니다. 하나라도 비면 판정하지 않고 빠진 항목과 이유를 보여줍니다 (`js/conditions.js`).

| 적용 | 항목 |
|---|---|
| 공통 | 매수 목적(거주/투자/거주+투자), 지역(시·군·구), 주택 유형, 전용면적, 매매가, 확보 자금, 보유 주택 수, 연소득, 매수 예정 시점 |
| 거주 | 업무지구 통근시간, 초등학교 도보시간 |
| 투자 | 역까지 도보시간, 같은 평형 최근 실거래가, 전세 시세, 계획 보유기간 |
| 재건축 | 정비사업 단계, 종전자산 감정가(사업시행인가~이주철거), 예상 분담금 |
| 세입자 승계 | 승계할 전세보증금 |

조건이 채워지면 규제·조건을 **차단 / 주의 / 정보**로 판정합니다. 예를 들면 다음과 같습니다.

- 토지거래허가구역 아파트는 전세 낀 매수와 비거주 매수가 불가합니다. 토지거래허가는 아파트에만 적용됩니다.
- 수도권·규제지역 비거주 매수는 6개월 전입의무 때문에 주담대를 쓸 수 없습니다.
- 투기과열지구 재건축을 조합설립인가 이후에 사면 조합원 지위양도 제한에 걸립니다(매도인 10년 보유·5년 거주 예외).
- **이주비**: 종전자산 감정가 × LTV 50%로 이주비 대출을 받고, 이주 시점 주담대 잔액을 대환한 뒤 남는 순수령액으로 세입자 보증금이나 임시거주 보증금을 마련합니다. 부족분은 매수 후 여유자금과 연 저축으로 채울 수 있는지 봅니다.
- 분담금 조달, 신축 입주 시점과 희망 입주 시점, 단기 양도(2년 미만), 보유기간 < 입주까지 기간을 점검합니다.

거주·투자 목적별로 입지 점수(통근·학교·역세권·호재/악재·주택유형)와 투자 점수(실거래 대비 가격·전세가율·환금성·재건축 수익)를 0~100점으로 냅니다.

## 무엇을 계산하나

| 영역 | 내용 |
|---|---|
| 대출 한도 | LTV(규제지역 40%, 생애최초 70%), 주담대 절대한도(15억 이하 6억 / 15~25억 4억 / 25억 초과 2억, 수도권 6억), DSR 40·50% + 스트레스 가산금리(수도권·규제 3.0%p, 지방 0.75%p × 금리유형 반영비율), 만기 30년 상한, 전입·토지거래허가·자금조달계획서 의무 |
| 정책모기지 | 디딤돌, 신생아 특례, 보금자리론 간이 자격 판정 |
| 취득 비용 | 취득세(1~3%, 6~9억 공식, 다주택 중과 8·12%), 지방교육세, 농특세, 생애최초 감면, 중개보수 상한요율, 국민주택채권 할인, 인지세, 등기 실비 |
| 보유세 | 재산세(공정시장가액비율 43~45%, 1주택 특례세율), 도시지역분, 지방교육세, 종부세(공제·세율표·재산세 중복공제·고령/장기보유 세액공제), 농특세. 2026 세제개편안(거주 1주택 공제 14억) 옵션 |
| 양도세 | 1세대1주택 비과세·12억 초과분 안분, 조정지역 거주요건, 장기보유특별공제 표1·표2, 단기세율, 지방소득세 |
| 매수 vs 임차 | 같은 현금·같은 월 주거비 예산으로 전세/월세와 순자산 비교(차액은 투자), 2년마다 갱신 비용, 매도 비용·양도세 반영, **손익분기 집값상승률**, **몬테카를로** 확률 |
| 리스크 | 금리 +1~3%p 상환 부담, 집값 −10~30% 지분·LTV, 전세가율·PIR·임대수익률, 깡통전세 경고 |
| 실거래가 | 국토부 실거래가 공개시스템 CSV(UTF-8·EUC-KR)를 올리면 해제거래 제외, 면적 ±3㎡ 비교사례로 ㎡당 가격 추세와 적정가 추정 |
| 비거주 투자 | 전세 낀 매수의 자기자본 수익을 같은 돈의 대안 투자와 비교 (보증금 증액·보유세·비거주 양도세 반영) |
| 매수 시점 | 지금 사기 vs 1~3년 임차 후 사기, 집값 시나리오별 비교 |
| 후보 비교 | 최대 4개 매물을 나란히 비교 |
| 종합 판정 | 위 지표를 양호/주의/경계/위험으로 표시하고 100점 점수와 "매수 적극 검토 / 조건부 검토 / 보류 권장 / 매수 불가"를 제시 |

## 구조

```
js/policy.js   규제·세율 파라미터 (규정이 바뀌면 이 파일만 수정)
js/engine.js   순수 계산 함수 (DOM 없음, Node 테스트 대상)
js/conditions.js 필수 조건 검증·규제 판정·재건축 이주비·시기·입지 점수
js/charts.js   의존성 없는 SVG 차트
js/app.js      화면 제어
tests/         node:test 단위 테스트
tools/build.js 단일 HTML 파일로 묶기
tools/server.js 로컬 서버 + 국토부 실거래가 API 프록시
```

## 명령

```bash
npm test          # 엔진 단위 테스트
npm run build     # dist/real-estate-analyzer.html 단일 파일 생성
npm start         # http://localhost:8080 로컬 서버 + 실거래가 자동 조회
DATA_GO_KR_KEY=<인증키> npm start   # 인증키를 서버에 설정 (화면 입력도 가능)
```

## 주의

- 결과는 의사결정 참고용입니다. 은행별 스트레스 DSR 반영비율, 정책대출 세부 요건, 세법 개정(2026-08-03 개편안은 국회 통과 전)은 달라질 수 있습니다.
- 공시가격은 시세 × 입력 비율(기본 69%)로 추정합니다. 정확한 값은 부동산 공시가격 알리미에서 확인해 비율을 조정하세요.
