사용 안내

메뉴마다 무엇을 넣으면 어떻게 계산되는지 영상으로 보여 줍니다. 영상 속 이름과 숫자는 모두 가상의 예시입니다.

앱으로 설치하기

설치하면 홈 화면 아이콘으로 바로 열리고, 인터넷이 끊겨도 마지막 화면을 볼 수 있습니다. 설치한 뒤에도 열 때마다 최신 버전으로 자동 갱신됩니다.

갤럭시 · 크롬

  1. 크롬에서 이 사이트를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴를 누릅니다.
  3. 홈 화면에 추가 → 설치를 누릅니다.

갤럭시 · 삼성 인터넷

  1. 아래쪽 ≡ 메뉴를 누릅니다.
  2. 현재 페이지 추가 → 홈 화면을 누릅니다.
  3. 주소창에 설치 아이콘이 보이면 그것을 눌러도 됩니다.

아이폰 · 사파리

  1. 사파리에서 이 사이트를 엽니다.
  2. 아래쪽 공유 버튼(네모에 화살표)을 누릅니다.
  3. 홈 화면에 추가 → 추가를 누릅니다.

PC · 크롬 / 엣지

  1. 주소창 오른쪽의 설치 아이콘을 누릅니다.
  2. 또는 화면 아래 메뉴의 앱 설치 버튼을 누릅니다.

설치한 뒤 알아 둘 것

  • 업데이트 — 인터넷이 연결된 상태로 열면 새 버전을 자동으로 받습니다. 화면이 예전 그대로면 앱을 완전히 닫았다가 다시 여세요.
  • 내 기준 옮기기 — 설치한 앱은 브라우저와 저장 공간이 다를 수 있습니다. 개인 설정 링크를 받았다면 앱 안의 내 맞춤 추천 → 내 기준 카드에 링크를 붙여넣고 내 기준 불러오기를 누르세요.
  • 인증키 — 실거래가(공공데이터포털), 카카오, 브이월드 키는 입력한 기기에만 저장되고 사이트에 올라가지 않습니다. 기기마다 한 번씩 넣어 주세요.
  • 개인 정보 — 보유 주택, 소득, 상환 능력 같은 값은 이 기기에만 저장됩니다. 공개 사이트에는 서울 시장 데이터만 올라갑니다.
