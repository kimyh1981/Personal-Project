차에 타면 자동으로 듣기 설정

기본값: 월~금 아침 6~8시에 차 블루투스가 연결되면 자동으로 읽습니다. 주말과 공휴일(대체공휴일·선거일 포함)에는 briefing.txt가 비어 있어 아무것도 읽지 않고, 이 화면에서는 언제든 들을 수 있습니다.

아이폰 (완전 자동) · 단축어 앱 → 자동화 → 새로운 자동화 → 블루투스 → 차 블루투스 선택 → 연결될 때, 즉시 실행.

  1. 동작 현재 날짜 → 날짜 형식 지정: 사용자 지정 H
  2. 동작 만약: 형식이 지정된 날짜가 6과 7 사이 (6시 0분~7시 59분)
  3. 만약 안에 동작 URL: briefing.txt → URL의 콘텐츠 가져오기 → 텍스트 말하기 (언어 한국어)

갤럭시 (완전 자동, Tasker) · 플레이스토어에서 Tasker를 설치하고 근처 기기(블루투스) 권한을 허용, 배터리 최적화에서 Tasker를 제한 없음으로 둡니다.

  1. 프로필 + → State → Net → BT Connected → Name에서 차 블루투스를 고릅니다. 프로필에 Time 06:00~08:00과 Day 월~금을 더합니다.
  2. 새 작업 '아침 뉴스'에 동작 세 개를 넣습니다.
    1. Task → Wait 5초 (차 오디오가 연결될 시간)
    2. Net → HTTP Request: Method GET, URL briefing.txt, Timeout 30
    3. Alert → Say: Text %http_data, Engine:Voice 구글 한국어, Stream Media, Respect Audio Focus 체크, If %http_data Is Set (공휴일에 빈 원고면 건너뜀)
  3. 프로필을 길게 눌러 Add Exit Task → Alert → Shut Up: 차에서 내리면(블루투스가 끊기면) 읽기를 멈춥니다.

Tasker 없이 쓰려면 모드 및 루틴으로 블루투스 연결 시 '아침 뉴스' 앱을 열고 듣기를 한 번 누르면 됩니다 (크롬은 한 번 눌러야 소리를 냅니다).
