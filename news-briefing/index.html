아침에만 듣고 싶으면 맨 앞에 현재 날짜 → 날짜 형식 지정(사용자 지정 H) → 만약 "결과가 11보다 작음"을 넣고, 위 세 동작을 그 안에 둡니다.

갤럭시 · 크롬으로 이 페이지를 열고 메뉴 → 홈 화면에 추가 / 앱 설치로 '아침 뉴스' 앱을 설치합니다. 설정 → 모드 및 루틴 → 루틴 추가 → 조건 블루투스 기기(차 선택, 연결됨) → 동작 앱 열기에서 '아침 뉴스'를 고릅니다.

안드로이드 크롬은 화면을 한 번 눌러야 소리를 낼 수 있어서, 앱이 열리면 듣기를 한 번 눌러 주세요. 터치 없이 들으려면 Tasker의 HTTP Get + Say 동작으로 위 주소를 읽게 하면 됩니다.
