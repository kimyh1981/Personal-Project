차에 타면 자동으로 듣기 설정

기본값: 월~금 아침 6~8시에 차 블루투스가 연결되면 자동으로 읽습니다. 주말과 공휴일(대체공휴일·선거일 포함)에는 briefing.txt가 비어 있어 아무것도 읽지 않고, 이 화면에서는 언제든 들을 수 있습니다.

아이폰 (완전 자동) · 단축어 앱 → 자동화 → 새로운 자동화 → 블루투스 → 차 블루투스 선택 → 연결될 때, 즉시 실행.

  1. 동작 현재 날짜 → 날짜 형식 지정: 사용자 지정 H
  2. 동작 만약: 형식이 지정된 날짜가 6과 7 사이 (6시 0분~7시 59분)
  3. 만약 안에 동작 URL: briefing.txt → URL의 콘텐츠 가져오기 → 텍스트 말하기 (언어 한국어)

갤럭시 (완전 자동, MacroDroid 무료) · 플레이스토어에서 MacroDroid를 설치하고 근처 기기(블루투스) 권한을 허용, 배터리 최적화에서 MacroDroid를 제한 없음으로 둡니다. 무료판의 매크로 5개 중 2개를 씁니다.

매크로 1 '아침 뉴스'

  1. 트리거: 연결 → 블루투스 이벤트 → 기기 연결됨 → 차 블루투스
  2. 동작: 다음 동작 전 대기 5초 (차 오디오가 연결될 시간)
  3. 동작: HTTP 요청 GET briefing.txt, 응답을 문자열 변수 briefing에 저장
  4. 동작: 텍스트 음성 변환(Speak Text): 텍스트 {lv=briefing}, 언어 한국어, 출력 스트림 미디어(음악)
  5. 제약 조건: 요일 월~금, 시간대 06:00~08:00

매크로 2 '내리면 멈춤': 트리거 블루투스 이벤트 → 기기 연결 끊김 → 차 블루투스, 동작 매크로 동작 취소 → '아침 뉴스'.

공휴일·주말에는 원고가 비어 있어 읽을 내용이 없습니다. MacroDroid 무료판은 앱 화면에만 광고가 나오고, 차에서 읽어 주는 동안에는 광고가 없습니다.

Tasker를 쓴다면 · 프로필 BT Connected(차) + Time 06:00~08:00 + Day 월~금 → 작업: Wait 5초 → HTTP Request GET briefing.txt → Say %http_data(Stream Media, If %http_data Is Set). 종료 작업은 Shut Up.

앱 없이 쓰려면 모드 및 루틴으로 블루투스 연결 시 '아침 뉴스' 앱을 열고 듣기를 한 번 누르면 됩니다 (크롬은 한 번 눌러야 소리를 냅니다).
