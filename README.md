# 부동산 투자·거주 분석기 (`re_analyzer`)

투자와 거주 목적의 주택 매수를 **필수 조건** 기준으로 판정하는 분석기입니다.
외부 라이브러리 없이 Python 3.10+ 로 동작하며, 금액 단위는 모두 **만원**입니다 (15억 = `150000`).

```bash
python3 -m re_analyzer --checklist                       # 필수 조건 목록
python3 -m re_analyzer examples/recon_live_seoul.json    # 텍스트 리포트
python3 -m re_analyzer examples/recon_live_seoul.json --json
python3 -m re_analyzer 입력.json --rules 내규정.json      # 규정 파일 교체
python3 -m unittest discover -s tests                    # 테스트
```

판정 결과: `진행가능` · `조건부`(주의 사항 있음) · `불가`(차단 사유 있음) · `입력보완필요`(필수 조건 누락)

## 필수 조건

| 구분 | 항목 | 입력 키 | 쓰이는 곳 |
|---|---|---|---|
| 목적 | 거주 / 투자 / 거주+투자 | `purpose` | 목적별 필수항목·대출 전입의무·점수 |
| 지역 | 시·도, 시·군·구(구까지) | `region.sido`, `region.sigungu` | 규제지역·토지거래허가구역·수도권 자동 판정 |
| 입지 | 통근·초등학교·역 도보(분), 호재/악재 | `location.*` | 거주 점수(거주 필수), 환금성(투자 필수) |
| 주택유형 | 아파트/단독주택/빌라/오피스텔, 전용면적 | `property.type`, `property.area_m2` | 토허제 적용(아파트), 농특세(85㎡ 초과), 환금성 |
| 확보자금 | 자기자금, 보유주택 수, 연소득, 기존 대출 원리금, 연저축 | `buyer.*` | 부족액, 취득세 중과, 다주택 대출 금지, DSR |
| 매매단가 | 매매가, 최근 실거래가, 전세 시세 | `price.*` | ㎡·평당가, 실거래 대비 프리미엄, 전세가율·갭 |
| 필요자금 | (계산) 취득세·지방교육세·농특세, 중개보수, 부대비용, 대출한도 | — | LTV·금액상한·스트레스 DSR 중 최소값 |
| 재건축 | 단계, 종전자산 감정가, 분담금, 신축 시세, 매도인 보유·거주연수, 임시거주 보증금 | `reconstruction.*` | 지위양도 제한, 이주비 대출, 이주·입주 시점 자금 |
| 시기 | 매수 시점, 보유기간, 희망 입주시점 | `timing.*` | 이주·신축 입주 예상, 단기양도·보유기간 불일치 |
| 규제 | (자동) 규제지역·토허구역·수도권, 필요 시 수동 지정 | `region.regulated`, `region.land_permit_zone` | 실거주 의무, 갭투자 차단, 대출 규제 |

필수 여부는 3단계입니다: **공통 필수**(항상), **목적별 필수**(거주 → 통근·학교 / 투자 → 역세권·실거래·전세·보유기간), **상황별 필수**(재건축 대상 → 단계·분담금 등, 세입자 승계 → 보증금). 전체 목록은 `--checklist`.

## 이주비 활용 재건축 분석

재건축 대상이면 매수 → 이주 → 신축 입주의 3개 시점으로 나눠 자금을 봅니다.

1. **매수 시**: 일반 필요자금 계산 (세입자 승계 시 보증금 차감)
2. **이주 시**: 이주비 대출(종전자산 × LTV, 수도권·규제지역 금액상한 적용)로 **이주 시점 주담대 잔액을 대환**한 뒤 남는 순수령액으로
   - 갭 매수: 세입자 보증금 반환
   - 실거주: 공사기간 임시거주 보증금 마련
   부족분 = 자기자금 필요 → 매수 후 여유자금 + 연저축 × 이주까지 기간과 비교
3. **입주 시**: 분담금 조달 가능 여부, 신축 시세 − 총비용(세금·비용·이자·분담금) = 예상 차익

또한 투기과열지구 조합설립인가 이후 매수 시 **조합원 지위양도 제한**(매도인 10년 보유·5년 거주 예외), 토허구역 실거주 의무와 이주 단계 충돌, 다주택 조합원 이주비 제한을 차단 사유로 표시합니다.

## 규정 파일

세율·대출규제·규제지역 목록은 코드가 아니라 [`re_analyzer/rules/kr_default.json`](re_analyzer/rules/kr_default.json)에 있습니다.
기본값은 **2025.6.27 가계부채 대책 + 2025.10.15 주택시장 안정화 대책** 기준이며, 정책이 바뀌면 이 파일만 수정하거나 `--rules`로 다른 파일을 넘기면 됩니다.

> ⚠️ 규정 값과 재건축 단계별 소요기간은 계획용 추정치입니다. 계약 전 반드시 국토부·금융위 최신 고시, 구청(토지거래허가), 은행 창구, 조합에서 확인하세요. 스트레스 DSR은 변동금리 기준(가산금리 100%)으로 보수적으로 계산합니다.

## 구조

```
re_analyzer/
  conditions.py     입력 모델 (필수 조건 항목)
  validation.py     필수 조건 정의·누락/오류 검사
  rules.py          규정 로딩, 규제지역·토허구역 판정
  finance.py        취득세·중개보수·LTV/금액상한/DSR·필요자금·대출 잔액
  reconstruction.py 재건축 지위양도·이주비·분담금·시점
  analyzer.py       전체 판정·점수
  report.py         텍스트/JSON 리포트
  rules/kr_default.json
examples/           실거주(분당), 재건축 실거주(노원), 재건축 갭(송파), 빌라(인천), 누락 예시
tests/
```
